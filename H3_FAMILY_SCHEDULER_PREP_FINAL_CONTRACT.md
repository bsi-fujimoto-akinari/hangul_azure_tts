# H3 Family Scheduler S3 PREP Final Contract

Contract ID: `H3-FAMILY-SCHEDULER-PREP-FINAL-20260924-V1`

## Scope

This contract normalizes the existing L/W/R/T Family Scheduler preparation
surfaces into one read-only three-state model. It does not author semantic
content, materialize preparation rows, issue learner sets, submit answers,
advance clocks or pointers, or mutate learner state.

`BLOCKED` is an orthogonal runtime gate state and is not one of the three
semantic preparation states.

## State semantics

| State | Meaning | Allowed next operation |
| --- | --- | --- |
| `READY` | A complete unissued family surface already exists. | Issue only through the separately authorized issue path. |
| `PREPARE_REQUIRED` | All semantic source material exists, but deterministic preissue materialization is still needed. | Deterministic preparation only; no semantic authoring. |
| `AUTHORING_REQUIRED` | Required semantic source material is missing. | Durable semantic authoring queue contract only; no issue or learner-state write. |
| `BLOCKED` | Runtime gate is not eligible. | No preparation or authoring action. |

## Read-only preview

Public function:

`h3FamilySchedulerPrepFinalPreview()`

Schema:

`H3_FAMILY_SCHEDULER_PREP_FINAL_V1`

The preview reads the existing runtime authorities and returns all four family
states plus source identity/provenance. It must report
`write_performed:false`.

The preview may call only non-materializing inspection helpers. In particular,
it must not call Reading/Translation materializers, listening payload
preparation, authoring queue upsert/ensure, any issue route, any submit route,
or post-commit scheduler mutation.

## Source authority rules

- Existing READY material remains authoritative and is never regenerated by S3.
- Deterministic preparation must preserve the exact source identity selected by
  the current family-specific contracts.
- AUTHORED_RETEST Translation surfaces retain
  `NO_OFFICIAL_PROVENANCE_CLAIM`; S3 must not promote them to official source.
- S3 does not change learner history, score, Review, 5W/5L/R/T
  pointers/counters, Family Scheduler clock, skill_queue/retest state, or
  existing ISSUED/COMMITTED rows.
